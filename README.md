#### Korta svar på frågorna:

1. Den huvudsakliga skillnaden är att git add förbereder ändringar genom att flytta dem från arbetskatalogen till staging area, medan git commit skapar en permanent ögonblicksbild av de förberedda ändringarna i arkivets historik.
2. Man använder branches för att testa koder och ändra hur mycket som helst utan att förstöra main koder. 
3. Det slår samman alla incheckningar från en gren till en enda ändring. Därefter slår alla branches till main, vilket håller historiken ren.
4. Att pusha till GitHub innebär att skicka lokala kodändringar till ett centralt versionkontrollsystem där koden sparas och historik sparas, men webbplatsen blir inte automatiskt synlig för allmänheten. Att publicera på Netlify är en hosting-tjänst som gör webbplatsen live och tillgänglig via en webbadress för besökare.
5. Man ta bort det från respository index och lägga den i gitignor filen.
